# Archipelago world

Python world for Archipelago (MIT, see [LICENSE](LICENSE)), in [gt2](gt2). Simulation Mode only for now. The player documentation is in [gt2/docs](gt2/docs).

## Layout

| File | Contents |
|---|---|
| `data/gt2.json` | Events and buyable cars, generated by [build_world_data.py](../scripts/data/build_world_data.py) from the dumps in [docs/game ids](../docs/game%20ids) (`events.json`, `dealers.json`, `cars.json`). Rebuild it after a dump changes. |
| `items.py` | Items, their IDs, and the PartIds each tuning part item unlocks |
| `locations.py` | Locations and their IDs |
| `options.py` | Options |
| `rules.py` | Event logic, with the [Rule Builder](https://github.com/ArchipelagoMW/Archipelago/blob/main/docs/rule%20builder.md) (the world is a `CachedRuleBuilderWorld`) |

## IDs (for the client)

| Item | ID |
|---|---|
| Progressive License | 1 |
| Trophy | 2 |
| Manufacturer: X | 100 + manufacturer ID ([manufacturers.md](../docs/game%20ids/manufacturers.md)) |
| Tuning part items | 200 + index in `PART_ITEMS`. Copy `n` of a progressive item unlocks `stages[n]`, a list of PartIds. The racing modification (PartId 34) is the 4th Progressive Weight Reduction. |
| Credits | 300 + index in `CREDIT_AMOUNTS` |

| Location | ID |
|---|---|
| Event won (1st place) | 1000 + event index (the `PlayerStats.eventResults` slot, see [events.md](../docs/game%20ids/events.md)) |
| License test passed | 2000 + tier × 10 + test (tier 1 = B, ..., 6 = S; test 0–9) |
| License earned | 2100 + tier |

The slot data has the generation options (`options`) and the starting manufacturer (`start_manufacturer`, `start_manufacturer_id`), which the client unlocks like a received item.

## Logic

An event's rule is `Has(Progressive License)` & the league rule (`Has(Trophy)`, or `CanReachLocation` on every race of the previous league) & `CarForEvent`, a custom rule: one of its allowed cars (`rules.eligible`: drivetrain, power limit on stock power, turbo, racing modification, dirt tyres, allowed list) has its manufacturer unlocked, costs no more than the price cap of the licenses held (`PRICE_CAPS`), and reaches the power target with the unlocked parts priced under that cap.

- Power is the stock power plus 90% (`GAIN_FACTOR`) of the gain of each part on its own, from [dealers.json](../docs/game%20ids/dealers.json). The best of the NA tune-ups and turbo kits counts, not both. Checked against the real maximum power, summed gains are within −17% / +8%.
- The target is 90% (`POWER_RATIO`) of the power limit, or `TIER_TARGETS` by license for events without a limit, capped at what the best allowed car reaches with every part. One-make events and the Event Synthesizer have no power target.
- Used cars count as available at their lowest price over the 60 periods of the used car lot.
- `CarForEvent` explains itself (the car it found, or the price cap and power it misses), which the Universal Tracker shows with `/explain`.
- Cars that another car of the same manufacturer beats in every way are dropped from each event's list (`rules.dominates`), to keep the rules fast.

## Testing

From an Archipelago 0.6.8 (or later) source checkout, with this folder linked or copied to `worlds/gt2`:

```bash
python -m pytest worlds/gt2
python fuzz.py -r 300 -j 12 -g gt2 -n 1
python fuzz.py -r 150 -j 12 -g gt2 -n 1 --hook worlds.tracker.fuzzer_hook:YamllessHook
```

`fuzz.py` comes from [Archipelago-fuzzer](https://github.com/Eijebong/Archipelago-fuzzer). The hooks need the Universal Tracker world in `worlds/tracker` and a `Players` folder in the Archipelago root.

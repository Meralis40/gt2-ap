# GT2 Archipelago

Gran Turismo 2 (Simulation and Arcade Mode) for [Archipelago](https://github.com/ArchipelagoMW/Archipelago).

You need your own NTSC-U 1.2 disc (Simulation SCUS-94488). No game data is distributed.

For how to play it, see the [Setup guide](world/gt2/docs/setup_en.md) and the [info](world/gt2/docs/en_Gran%20Turismo%202.md)
on what is randomized.

# Event opponents

Generated by `scripts/data/dump_opponents.py` from the Simulation disc (USA). `opponents.json` holds the same data, with the opponent entries of each event.

- An event's opponents are drawn at random from its list of up to 16 car entries of the race data (`RaceSetup_InitEvent`). Each entry is a car with its own tuned setup, so the same car can have several entries.
- **Power** and **weight** are what the game computes for an entry (`CarParams_GetPerformance`, as `BattleTable_LoadNext` does). The power is in the unit of the power limits.
- The free races (`FREERACE*`, `FREECHAMP*`) don't use their list: `GTBattleMenu` draws the opponents from the car table, around the player's power. The rally events race one recorded car.

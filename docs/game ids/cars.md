# Cars

Generated by `scripts/data/dump_cars.py` from the Simulation disc (USA). `cars.json` holds the same data.

- **Code** is the 5-character car code (`CarCode_Encode`); the list is the game-data car table (table 30), which also holds race-only and opponent cars.
- **Drivetrain** comes from `Car.stat94` bits 13-15, as computed when a car is bought.
- **Engine** is the three engine strings of the engine table (table 6): layout, valvetrain, and aspiration (NA, TURBO, MA = supercharger). Blank (`-`) strings are left out. These are the game's data, so some are wrong (the Vectra GSi 2.5 V6 is listed as I4).
- Manufacturer `#35` is never shown as a dealership; its cars are Vauxhall models (see `manufacturers.md`).
- **Power** is the value in `Car.flags98` bits 0-13, the one `Race_CheckEntry` compares with an event's power limit. The game computes it from the torque curve and the installed parts; the script runs that code (`Car_StoreSetup`) in an emulator.
- **Max power** has every available part at its highest stage, racing modification included, plus the best NA tune-up or turbo kit (**Kit**). A turbo kit resets the NA tune-up and the reverse, so only one of them counts.
